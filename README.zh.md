# dsh-sidebar-fold

侧栏折叠与显示管理：收起侧栏上方的面板入口，并集中管理左侧、对话窗口顶部/底部、标签栏和设置页分别显示哪些插件条目。只管「显示」，不启用或停用任何插件。

[English](./README.md)

## 它做什么

DSH 的 Web 外壳会把插件内容同时铺在四个地方：左侧面板列表、对话窗口顶部、对话窗口底部、设置页。插件装多了，每一处都会挤。这个插件给你两件事：

1. **折叠面板列表。** 侧栏面板列表与「工作区」之间的接缝上有一条细折叠条，点一下把面板列表收起，整段高度让给工作区——小屏幕上的主要痛点。再点一下展开，折叠状态按窗口持久化。

2. **显示管理。** 主面板里有一页（设置页也有一节），按区域列出当前真正渲染的条目。关掉某个条目，它就不再出现在该处；随时能在这里打开。被隐藏的条目照常运行，变的只是界面上出不出现。

## 边界（重要）

本插件只管**显示**：不会写 `cordis.patch.yml`、不改插件市场的状态、不卸载或禁用任何插件。隐藏一个条目只是让它从界面上不出现，插件本身照常运行，随时能在同一页打开。

本插件自己也遵守同一套规则：它可以在侧栏出现（面板入口 + 管理页），也可以在设置页出现（一整页开关），两个位置至少保留一个——全关掉就再也找不回来了，界面会拦住这种操作。

有一组控件在当前布局里共用同一个容器、分不出彼此，因此显示为「暂不可隐藏」，而不是硬猜着隐藏。

## 管理的区域

| 区域 | 覆盖 |
| --- | --- |
| 左侧面板列表 | 侧栏里的插件入口（`sidebar.panellist`） |
| 对话窗口顶部 | 会话标题旁的操作、工具、角落与 lineage 槽位 |
| 对话窗口标签栏 | `对话 / 轨迹 / 上下文 / 编队` 这一排视图切换 |
| 对话窗口底部 | 输入框左右的控件，以及它上方和下方的附加条 |
| 设置页 | 设置左侧那串分区 |

## 安装

```sh
dsh plugin --profile web add Roambus/dsh-sidebar-fold
```

## 要求

- `package.json` 需声明 `dsh.bundle` manifest 并指向 `cordis.patch.yml`（已包含）。
- 只有浏览器半边界面，运行时不需要额外安装官方 `@deepseek-ai/*` 包。
